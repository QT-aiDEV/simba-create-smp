SIMBA CREATE SMP

BUILD • EXPLORE • SURVIVE

A friendly Create-powered SMP where every factory feeds a world worth living in.

Simba Create SMP is a big, friendly Minecraft 1.21.1 NeoForge modpack built for shared worlds that grow into stories. Start with a waterwheel and a rail line; end up with factories, colonies, aircraft, underwater bases, industrial towns, and the defenses to keep them standing.

This is a Create-first multiplayer pack, not a pile of unrelated mods. The core loop is simple: build useful infrastructure, use it to reach the next frontier, then prepare together for a world that pushes back.

Build the Machine

Create 6 is the heart of Simba. Design real production lines, kinetic factories, trains, storage networks, power systems, fuel processing, and decorated workshops that feel like part of a living settlement.

  • Create machinery, logistics, decoration, copycats, and automation
  • Steam 'n' Rails, tracks, signals, maps, utilities, and train-focused building
  • Create New Age, Crafts & Additions, Diesel Generators, TFMG, nuclear power, petrochemistry, ore processing, and industry addons
  • Create Gunsmithing, Big Cannons, armored constructs, and factory-made gear

Settle a World Worth Keeping

Your factory has somewhere to belong. Build a small homestead, a shared port, or a sprawling industrial city with colonies, roads, bridges, farms, rich decoration, and custom tree-filled landscapes.

  • MineColonies and CreateColonies for living settlements and long-term projects
  • Tectonic terrain, Middgard, Lithostitched, Oh The Trees You'll Grow, and Treeplacer for dramatic places to build
  • Rechiseled, Chipped, Design n' Decor, handcrafted building, bridges, lights, storage, furniture, paintings, and workshop detail
  • The Roads More Travelled lets early adventures leave visible paths behind

Land, Sea, Sky, and Rails

Simba gives Create projects a destination. Lay out rail networks, take to the air, build freight routes, make a deep-sea outpost, or punch a Hypertube across your growing world.

  • Create Aeronautics and curated addons for moving contraptions and flight
  • Create Deep Seas for forgiving-but-meaningful underwater engineering
  • Hypertubes, aircraft, rail navigators, maps, and long-haul infrastructure
  • BlueMap for a beautiful live view of the shared server world

Build Up. Then Survive It.

Factories should matter when night falls. Simba keeps the cooperative survival loop alive with combat progression, raid pressure, and slow, dramatic horde nights—without turning every trip outside into a chore.

  • Better Combat, Simply Swords, Epic Knights, cosmetic armor, and weapon display
  • Illager Invasion, mutants, zombie variety, enhanced hordes, and Undead Nights
  • Slow, dense horde zombies that burn at dawn: build defenses, then enjoy the relief of sunrise
  • Graves, sleeping bags, shields, food, farming, and recovery tools that make multiplayer setbacks recoverable rather than miserable

Made for Friends

The pack is tuned for a cooperative server from the start. Share builds, talk while you work, carry a machine into place, keep your gear safe, and focus on the next group project instead of fighting setup problems.

  • Simple Voice Chat, teams, claims/protection, backups, ranks, and server tools
  • JEI, Curios, Carry On, whole-tree felling, magnets, trowels, zoom, storage, graves, sleeping bags, and inventory quality-of-life
  • Heavy and Lite client profiles join the same gameplay/server stack
  • Heavy adds the full Simba presentation, visual polish, ambience, and optional resource packs; Lite lowers client-side visual overhead without changing play

Current Release: 0.15.0

0.15.0 updates the Create: Pipes'n Physics stack while preserving existing instant-transfer pipe behavior for compatibility. It also includes coordinated updates across the map, FTB, Supplementaries/Moonlight, Petrochem, Oritech, Gunsmithing, Aeronautics, Create addon, storage, and server utility stacks. The release keeps deliberate compatibility pins where newer files caused world-generation, colony initialization, or recipe-viewer regressions.

Recommended download: Heavy for the full Simba experience.
Need a lighter client? Use Lite—gameplay compatibility stays the same.
Hosting a world? The matching Server Pack is available as an additional file under the Heavy release.
