# Create BlueMap extensions

`createentityaddon-1.1.5-5.7.jar` is a BlueMap 5.7 resource extension. It adds
Create contraption, track, copycat, windmill, and train-carriage rendering to
BlueMap. It is loaded by BlueMap from this folder at server startup.

The matching `Create BlueMap` NeoForge server mod is kept separately in the
server `mods` folder. Both are staged for the next dedicated-server restart.
