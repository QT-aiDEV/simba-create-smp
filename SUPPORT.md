# Support

## Before opening an issue

1. Confirm you are using the matching Simba release and Minecraft `1.21.1`.
2. Use Java `21` and the NeoForge version bundled by the pack.
3. Reproduce once without adding or removing mods.
4. Check the latest CurseForge file changelog for known issues.
5. Search existing GitHub issues.

## What belongs in GitHub Issues

- repeatable crashes or startup failures;
- broken recipes, quests, configs, or pack defaults;
- Heavy/Lite compatibility problems;
- dedicated-server pack defects;
- mod, balance, and quality-of-life suggestions.

General Minecraft account problems, launcher authentication failures, and support for modified copies of the pack may need to be handled by Mojang, the launcher vendor, or the relevant mod author.

## Useful evidence

Attach a crash report or paste the smallest relevant log section. Include the Simba version, profile, Java version, what you expected, what happened, and exact reproduction steps.

Redact server addresses, tokens, email addresses, player IPs, and other private data. Do not upload complete worlds or player-data folders to a public issue.
